На входе модель получает аудиофайл.

Задача модели разделить дорожки инструментов и голоса. Распознать мелодию, аккорды, бой, слова и на выходе выдать файл, который сможет интерпретировать модуль интерактивного воспроизведения.

# Что должна различать модель

1. Мелодию при игре отдельных нот

2. Ритмический рисунок и аккорды при игре боем

3. Слова песни

*всё это должно войти в итоговую табулатуру*

# Бонусные фичи

*если основной функционал реализован на хорошем уровне*

1. Распознавание гитарных приёмов (щелчки, игра с приглушением, удары по гитаре... )

2. Возможность генерировать табулатуру из ссылки на YouTube.

3. Генерация табулатур для тех песен, где нет гитары

# Гитарные приёмы:

- **h** (hammer-on): лёгкий удар пальцем по струне, который позволяет извлечь следующую ноту без использования медиатора.

- **p** (pull-off): обратный приём, при котором палец резко снимается со струны, и звучит более низкая нота.

- **b** (bend): подтяжка струны, при которой высота звука меняется плавно, без отдельного удара.

- **/** слайд, то есть плавное скольжение пальца от одного лада к другому без отрыва от струны.

- **x**: приглушенная струна, по которой просто проводят рукой или медиатором, без четкого звука.
