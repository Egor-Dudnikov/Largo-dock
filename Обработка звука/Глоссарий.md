# 1. Музыкальные термины

## 1.1. Звук и его параметры

| Термин                    | Определение                                                              |
| ------------------------- | ------------------------------------------------------------------------ |
| **Высота тона (pitch)**   | Воспринимаемая «высокость» звука; определяется частотой колебаний        |
| **Частота (Гц)**          | Число колебаний в секунду; нота Ля первой октавы — 440 Гц                |
| **Основная частота (F0)** | Самая низкая и сильная частота в звуке, определяющая воспринимаемую ноту |
| **Атака (attack)**        | Первый резкий момент звука — щипок или удар по струне                    |
| **Затухание (decay)**     | Постепенное угасание звука после щипка                                   |
| **Обертоны**              | Дополнительные частоты выше основной, создающие тембр                    |
| **Громкость (loudness)**  | Сила звука; зависит от амплитуды и расстояния до микрофона               |
| **Сила удара (velocity)** | Параметр 0–127 в MIDI, передающий относительную динамику: тихо/громко    |

## 1.2. Ноты и гармония

| Термин                            | Определение                                                           |
| --------------------------------- | --------------------------------------------------------------------- |
| **Нота**                          | Обозначение звука: До, Ре, Ми, Фа, Соль, Ля, Си (C, D, E, F, G, A, B) |
| **Интервал**                      | Расстояние между двумя нотами                                         |
| **Аккорд**                        | Несколько нот, звучащих одновременно (Am, F, C, G)                    |
| **Тризвучие**                     | Аккорд из трёх нот (например, C-E-G)                                  |
| **Тональность (key)**             | «Главная» нота и лад, вокруг которых строится музыка                  |
| **Аккордовая сетка (chord grid)** | Последовательность аккордов во времени: `0:00 Am`, `0:05 F`           |

## 1.3. Ритм и время

| Термин                              | Определение                                                             |
| ----------------------------------- | ----------------------------------------------------------------------- |
| **Темп (BPM)**                      | Число ударов в минуту                                                   |
| **Доля (beat)**                     | Основная пульсация трека                                                |
| **Такт (bar, measure)**             | Группа долей, обычно 4                                                  |
| **Размер (time signature)**         | Сколько долей в такте: 4/4, 3/4, 6/8                                    |
| **Длительность ноты**               | Сколько нота звучит: целая, половинная, четверть, восьмая, шестнадцатая |
| **Downbeat**                        | Первая (сильная) доля такта                                             |
| **Onset**                           | Момент начала звука (атака ноты)                                        |
| **Метроном**                        | Ровный щелчок под темп                                                  |
| **Паттерн боя (strumming pattern)** | Последовательность ударов вниз/вверх по струнам                         |

## 1.4. Гитара и аппликатура

| Термин | Определение |
|---|---|
| **Струна** | На акустической гитаре 6 струн; нумерация от тонкой (1) к толстой (6) |
| **Лад (fret)** | Металлическая перекладина на грифе; зажатие струны на ладу меняет высоту |
| **Открытая струна (open string)** | Струна без зажатия |
| **Аппликатура (fingering)** | Распределение нот по струнам и ладам |
| **Позиция** | Область грифа, где играет левая рука |
| **Барре (barre)** | Зажатие нескольких струн одним пальцем |
| **Растяжка** | Расстояние между зажатыми ладами |
| **Строй (tuning)** | Настройка струн: Standard E, Drop D, DADGAD |
| **Каподастр (capo)** | Зажим на грифе, поднимающий строй |
| **Перебор (арпеджио)** | Струны щиплются поочерёдно, а не все сразу |
| **Бой (strumming)** | Удар по нескольким струнам сразу |
| **Fingerstyle** | Игра пальцами: мелодия + бас одновременно |
| **«Шестёрка», «восьмёрка»** | Классические схемы перебора |
| **Табулатура (табы)** | Запись музыки для гитары: 6 линий = 6 струн, цифры = лады |

## 1.5. Приёмы игры

| Термин                  | Определение                                                         |
| ----------------------- | ------------------------------------------------------------------- |
| **`h` (hammer-on)**     | Лёгкий удар пальцем по струне, извлекающий следующую ноту без щипка |
| **`p` (pull-off)**      | Обратный приём: палец резко снимается, звучит более низкая нота     |
| **`b` (bend)**          | Подтяжка струны, плавно меняющая высоту без отдельного удара        |
| **`/` (slide)**         | Плавное скольжение пальца от одного лада к другому без отрыва       |
| **`x` (dead note)**     | Приглушённая струна: шумовой звук без чёткой высоты                 |
| **Muted (приглушение)** | Удар с приглушением струн ладонью или пальцами                      |

## 1.6. Представление музыки

| Термин          | Определение                                             |
| --------------- | ------------------------------------------------------- |
| **Полифония**   | Несколько нот одновременно                              |
| **Монофония**   | Одна нота в момент времени                              |
| **Нотный стан** | Пять линий для записи нот                               |

# 2. Технические термины

## 2.1. Форматы аудиофайлов

| Термин         | Определение                                                   |
| -------------- | ------------------------------------------------------------- |
| **WAV**        | Несжатый аудиоформат; эталон — 44.1 кГц, 16 бит, stereo       |
| **MP3**        | Сжатый аудиоформат с потерями; используется для лёгких стемов |
| **FLAC**       | Сжатый без потерь                                             |
| **M4A**        | Контейнер AAC                                                 |
| **MIDI**       | Цифровой формат событий: нота, время, сила удара              |
| **MIDI-нота**  | Число 0–127, обозначающее высоту; Ля первой октавы — 69       |
| **Velocity**   | Сила удара в MIDI                                             |
| **Pitch bend** | Кривая отклонения высоты, сохраняемая в MIDI                  |
| **MusicXML**   | Открытый формат нотной записи для обмена                      |
| **AlphaTex**   | Текстовый формат табулатуры AlphaTab                          |

## 2.3. Обработка и анализ сигнала

| Термин               | Определение                                                            |
| -------------------- | ---------------------------------------------------------------------- |
| **SNR**              | Отношение сигнал/шум; влияет на точность анализа                       |
| **RMS-нормализация** | Приведение средней громкости файла к эталонному уровню                 |
| **Спектрограмма**    | Представление спектра звука во времени                                 |
| **Spectral flux**    | Мера изменения спектра между кадрами; используется для onset detection |
| **Стем (stem)**      | Отдельная дорожка микса: вокал, барабаны, бас, гитара                  |

## 2.5. Детекция и ритмический анализ

| Термин                 | Определение                                                |
| ---------------------- | ---------------------------------------------------------- |
| **Pitch detection**    | Определение высоты звука                                   |
| **Onset detection**    | Поиск моментов атаки                                       |
| **Beat tracking**      | Определение долей и темпа                                  |
| **Downbeat detection** | Определение первой доли такта                              |
| **Квантование**        | Привязка нот к математической сетке темпа (1/4, 1/8, 1/16) |

## 2.8. Сравнение и оценка исполнения

| Термин                         | Определение                                       |
| ------------------------------ | ------------------------------------------------- |
| **DTW (Dynamic Time Warping)** | Выравнивание двух последовательностей по времени  |
| **Отклонение (deviation)**     | Насколько раньше/позже эталона сыграна нота, в мс |
| **Точность (accuracy)**        | Доля правильных нот                               |
